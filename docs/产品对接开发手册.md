## 1. 系统架构概览

### 1.1 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Node.js + Express 5.x |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis（任务会话） |
| 前端 | Vue 3 + Element Plus |
| 语义识别 | @huggingface/transformers |
| 认证 | JWT |

### 1.2 目录结构

```
├── config/          # 配置管理
├── db/              # 数据库连接池
├── middleware/      # 中间件（认证、限流、错误处理）
├── repositories/    # 数据访问层
├── routes/          # API路由
├── rules/           # 对话规则引擎
├── services/        # 业务服务层
│   └── taskflow/    # 任务流程引擎
├── src/             # 核心识别引擎
├── frontend/        # Vue前端源码
├── public/          # 构建产物
├── scripts/         # 脚本工具
├── server.js        # 服务入口
└── faq-engine.js    # 对话编排引擎
```

### 1.3 核心流程

```
用户输入
    ↓
[无意义检测] → 无意义 → 返回固定话术
    ↓ 有意义
[任务流程检查] → 有活跃任务 → 任务对话模式
    ↓ 无任务
[路由判定] → 命中触发词 → 启动任务流程
    ↓ 未命中
[FAQ意图识别] → 匹配成功 → 返回答案
    ↓ 未匹配
[兜底回复] → 返回业务引导话术
```

## 3. 核心API接口

### 3.1 聊天接口

#### 3.1.1 发送消息

**接口**: `POST /api/chat`

**认证**: 无需

**请求**:
```json
{
  "text": "你好",
  "sessionId": "session_001",
  "userId": "user_123",
  "channelType": "web",
  "debug": false
}
```

**参数说明**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| text | string | 是 | 用户输入文本 |
| sessionId | string | 否 | 会话ID，用于上下文关联 |
| userId | string | 否 | 用户标识 |
| channelType | string | 否 | 渠道标识（web/wechat/mp/app/api） |
| debug | boolean | 否 | 是否返回调试信息 |

**响应**:
```json
{
  "matched": true,
  "confidence": 0.92,
  "intent_code": "greeting",
  "intent_name": "问候语",
  "answer": "您好！有什么可以帮您？",
  "source": "direct"
}
```

**响应字段**:

| 字段 | 类型 | 说明 |
|------|------|------|
| matched | boolean | 是否匹配到FAQ |
| confidence | number | 匹配置信度（0-1） |
| intent_code | string | 匹配的意图编码 |
| intent_name | string | 意图名称 |
| answer | string | 回复内容 |
| source | string | 来源类型 |
| candidates | array | 候选列表（追问时返回） |
| richContent | object | 富媒体内容 |
| links | array | 相关链接 |
| related | array | 相关推荐 |
| events | array | 事件列表（如转人工） |
| _debug | object | 调试信息（debug=true时） |

**source取值**:

| 值 | 说明 |
|------|------|
| direct | 高置信度直接回答 |
| confirmed | 追问后确认 |
| clarify | 追问确认中 |
| fallback | 兜底回复 |
| meaningless | 无意义输入 |
| complaint | 投诉安抚 |
| task_started | 任务开始 |
| task_progress | 任务进行中 |
| task_complete | 任务完成 |
| task_cancelled | 任务取消 |
| task_resumed | 任务恢复 |
| task_suspended_faq | FAQ插话（任务挂起） |
| route_clarify | 路由澄清 |

#### 3.1.2 调试模式

设置 `debug: true` 时，响应附加 `_debug` 字段：

```json
{

    "confidence": 0.92,
    "task": {
      "taskCode": null,

    }
  }
}
```

## 4. 数据模型

### 4.1 FAQ条目

```sql
CREATE TABLE faq (
  id INT AUTO_INCREMENT PRIMARY KEY,
  code VARCHAR(100) NOT NULL UNIQUE,
  name VARCHAR(200) NOT NULL,
  samples TEXT NOT NULL,           -- 相似问，换行分隔
  answer TEXT NOT NULL,
  category_id INT,
  rich_content JSON,               -- 富媒体内容
  links JSON,                      -- 相关链接
  related JSON,                    -- 相关推荐
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 4.2 聊天日志

```sql
CREATE TABLE chat_log (
  id INT AUTO_INCREMENT PRIMARY KEY,
  session_id VARCHAR(100),
  user_id VARCHAR(100),
  channel_type VARCHAR(20) DEFAULT 'web',
  user_text TEXT,
  intent_code VARCHAR(100),
  confidence DECIMAL(5,4),
  source VARCHAR(50),
  answer TEXT,
  meaningful TINYINT DEFAULT 1,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_channel_time (channel_type, created_at),
  INDEX idx_intent (intent_code),
  INDEX idx_created (created_at)
);
```

### 4.3 系统配置

```sql
CREATE TABLE sys_config (
  id INT AUTO_INCREMENT PRIMARY KEY,
  config_key VARCHAR(100) NOT NULL UNIQUE,
  config_value TEXT,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

**常用配置键**:

| Key | 说明 | 值类型 |
|-----|------|--------|
| min_confidence | 最低置信度 | number |
| clarify_threshold | 追问阈值 | number |
| cancel_words | 取消词 | JSON数组 |
| reply_texts | 回复话术 | JSON对象 |
| channel_types | 渠道类型 | JSON数组 |
| ner_types | NER类型 | JSON数组 |

### 4.4 任务定义

```sql
CREATE TABLE task_definition (
  id INT AUTO_INCREMENT PRIMARY KEY,
  code VARCHAR(100) NOT NULL UNIQUE,
  name VARCHAR(200) NOT NULL,
  definition JSON NOT NULL,        -- 完整任务定义
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 7. SDK集成示例

### 7.1 JavaScript/Node.js

```javascript
const BASE_URL = 'http://localhost:3001'

class FAQBotClient {
  constructor(options = {}) {
    this.baseUrl = options.baseUrl || BASE_URL
    this.sessionId = options.sessionId || `session_${Date.now()}`
    this.userId = options.userId || null
    this.channelType = options.channelType || 'web'
  }

  async chat(text) {
    const response = await fetch(`${this.baseUrl}/api/chat`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        text,
        sessionId: this.sessionId,
        userId: this.userId,
        channelType: this.channelType,
      }),
    })
    return response.json()
  }
}

// 使用示例
const bot = new FAQBotClient({
  sessionId: 'user_session_001',
  userId: 'user_123',
  channelType: 'web',
})

const result = await bot.chat('你好')
console.log(result.answer)
```

### 7.2 Python

```python
import requests
import uuid

class FAQBotClient:
    def __init__(self, base_url='http://localhost:3001', channel='web'):
        self.base_url = base_url
```

### 7.3 Java

```java
import java.net.http.*;
import java.net.URI;

public class FAQBotClient {
    private static final String BASE_URL = "http://localhost:3001";
    private final String sessionId;
    private final String channel;
    private final HttpClient client = HttpClient.newHttpClient();

    public FAQBotClient(String channel) {
        this.sessionId = "session_" + System.currentTimeMillis();
        this.channel = channel;
    }

    public String chat(String text) throws Exception {
        String json = String.format(
            "{\"text\":\"%s\",\"sessionId\":\"%s\",\"channelType\":\"%s\"}",
            text, sessionId, channel
        );

        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(BASE_URL + "/api/chat"))
            .header("Content-Type", "application/json")
            .POST(HttpRequest.BodyPublishers.ofString(json))
            .build();

        HttpResponse<String> response = client.send(
            request, HttpResponse.BodyHandlers.ofString()
        );

        return response.body();
    }
}
```
