## 1. 产品概述

### 1.1 产品定位

智能体管理平台是一个面向企业的**对话式AI大脑**，提供FAQ问答、任务型对话、多渠道接入等核心能力。通过API为各类终端（网页、微信公众号、小程序、APP等）提供智能对话服务。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| FAQ智能问答 | 基于语义相似度匹配，支持多轮追问确认 |
| 任务型对话 | 引导式信息收集（如预约、报修），支持槽位提取 |
| 多渠道接入 | 网页、微信、小程序、APP、API等 |
| 大模型兜底 | FAQ未匹配时可调用LLM生成回答 |
| 运营分析 | 聊天记录分析、低置信度问题追踪、优化建议 |

### 1.3 系统架构

```
用户终端 → API网关 → 对话引擎 → 意图识别/任务流程
                              ↓
                        知识库/配置中心
                              ↓
                        日志/统计分析
```

## 2. 快速入门

### 2.1 访问地址

| 入口 | 地址 | 说明 |
|------|------|------|
| 聊天测试 | `http://<服务器地址>:3001/` | 独立聊天客户端，用于测试 |
| 管理后台 | `http://<服务器地址>:3001/admin/` | 管理后台，配置知识库、查看日志等 |

### 2.2 登录管理后台

1. 打开浏览器访问管理后台地址
2. 输入管理员账号密码（默认：admin / admin123）
3. 点击「登录」进入管理后台

### 2.3 首次使用流程

```
1. 登录管理后台
2. 创建FAQ分类 → 添加FAQ问答对
3. （可选）配置任务流程
4. 在聊天客户端测试对话效果
5. 查看监控日志，持续优化
```

## 3. 功能模块详解

### 3.1 FAQ管理

**位置**: 管理后台 → FAQ管理

#### 3.1.1 分类管理

- **新建分类**: 点击「新建分类」，输入分类名称和描述
- **编辑/删除**: 点击分类右侧操作按钮

#### 3.1.2 FAQ条目管理

每个FAQ条目包含：

| 字段 | 说明 | 示例 |
|------|------|------|
| 问题编码 | 唯一标识 | `greeting` |
| 问题名称 | 显示名称 | `问候语` |
| 相似问 | 多种表达方式 | `你好`、`hello`、`在吗` |
| 答案 | 匹配后回复的内容 | `您好！有什么可以帮您？` |
| 分类 | 所属类别 | `基础问答` |

**操作步骤**:
1. 选择左侧分类
2. 点击「新建FAQ」
3. 填写问题编码、名称、相似问（每行一条）
4. 填写答案内容
5. 点击「保存」

### 3.2 任务流程管理

**位置**: 管理后台 → 任务管理 → 流程设计

#### 3.2.1 任务流程概念

任务流程用于引导式信息收集，典型场景：
- 预约上门服务
- 报修登记
- 投诉处理

#### 3.2.2 创建任务流程

1. 进入「任务管理」→「流程设计」
2. 点击「新建任务」
3. 填写基本信息：
   - **任务编码**: 唯一标识（如 `repair_service`）
   - **任务名称**: 显示名称（如 `报修服务`）
   - **触发词**: 用户说哪些话会触发此任务
4. 设计流程步骤：
   - 添加「收集信息」步骤（槽位）
   - 配置提问话术、提取规则
5. 保存并发布

#### 3.2.3 槽位配置

每个收集步骤需要配置：

| 配置项 | 说明 |
|--------|------|
| 槽位名称 | 字段标识（如 `phone`） |
| 提问话术 | 引导用户输入的话术 |
| 提取规则 | 正则/NER类型/枚举值 |
| 是否必填 | 必填项会持续追问 |

### 3.3 对话规则配置

**位置**: 管理后台 → 对话规则

可配置的规则：

| 规则类型 | 说明 |
|----------|------|
| 确认词 | 用户确认的表达（如"是的"、"对"） |
| 否定词 | 用户否认的表达（如"不是"、"不对"） |
| 取消词 | 用户取消任务的表达 |
| 无意义检测 | 过滤乱码、无意义输入 |
| 会话超时 | 会话过期时间（默认30分钟） |

### 3.4 系统配置

**位置**: 管理后台 → 系统配置

#### 3.4.1 基础配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 最低置信度 | 0.5 | 低于此值视为未匹配 |
| 追问阈值 | 0.65 | 介于两者之间时追问确认 |
| 返回数量 | 5 | 候选结果数量 |

#### 3.4.2 话术配置

可自定义各类回复话术：

| 话术类型 | 说明 |
|----------|------|
| 无意义回复 | 检测到乱码时的回复 |
| 兜底回复 | 未匹配任何问题时的回复 |
| 追问确认 | 中置信度时的追问话术 |
| 投诉安抚 | 检测到投诉情绪时的安抚话术 |

#### 3.4.3 接入渠道管理

配置支持的接入渠道：

| 渠道编码 | 渠道名称 |
|----------|----------|
| web | 网页 |
| wechat | 微信公众号 |
| mp | 小程序 |
| app | APP |
| api | API |

可新增、编辑、删除渠道。修改后立即生效。

#### 3.4.4 NER类型管理

配置命名实体识别类型，用于槽位提取：

- **系统内置**: address（地址）、phone（电话）、name（姓名）等
- **自定义正则**: 可新增正则表达式类型

### 3.5 监控中心

**位置**: 管理后台 → 监控中心

#### 3.5.1 最近咨询记录

查看实时对话记录：

| 字段 | 说明 |
|------|------|
| 时间 | 对话时间 |
| 用户 | 用户ID |
| 渠道 | 接入渠道 |
| 问题 | 用户输入 |
| 匹配意图 | 命中的FAQ编码 |
| 置信度 | 匹配置信度 |
| 来源 | direct/clarify/fallback等 |

**筛选功能**:
- 按日期筛选
- 按关键词筛选
- 按渠道筛选

#### 3.5.2 未匹配问题

查看未被知识库覆盖的问题，用于补充FAQ。

#### 3.5.3 低置信度问题

查看匹配不确定的问题，用于优化相似问。

### 3.6 会话调试

**位置**: 管理后台 → 会话调试

用于调试特定会话的完整对话流程：

1. 输入会话ID
2. 查看完整的对话轨迹
3. 查看每一步的判定逻辑（无意义检测、意图识别、路由判定等）
4. 查看LLM调用详情

### 3.7 问题追踪

**位置**: 管理后台 → 问题追踪

跟踪和处理用户反馈的问题：

| 状态 | 说明 |
|------|------|
| 待处理 | 新发现的问题 |
| 处理中 | 正在优化 |
| 已解决 | 问题已修复 |
| 已忽略 | 无需处理 |

## 4. 常见问题

### Q1: 用户输入总是返回兜底回复？

**可能原因**:
1. 知识库中没有对应的FAQ
2. 相似问太少，语义覆盖不足
3. 最低置信度设置过高

**解决方案**:
1. 在FAQ管理中添加对应问答对
2. 为现有FAQ添加更多相似问
3. 在系统配置中适当降低最低置信度

### Q2: 任务流程没有触发？

**可能原因**:
1. 触发词配置不足
2. 用户表达与触发词差异过大

**解决方案**:
1. 在任务流程中添加更多触发词
2. 使用更通用的触发词

### Q3: 修改配置后没有生效？

**说明**: 大部分配置修改后立即生效，无需重启服务。

如果确实未生效，可尝试刷新页面或重新登录。

### Q4: 如何查看系统运行状态？

访问健康检查接口：`http://<服务器地址>:3001/api/health`

返回信息包含：
- 服务运行时长
- 内存使用情况
- FAQ加载数量
- 数据库连接状态
