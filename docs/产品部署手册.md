## 1. 环境要求

### 1.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 2核 | 4核+ |
| 内存 | 2GB | 4GB+ |
| 磁盘 | 10GB | 20GB+ |
| 操作系统 | Linux/Windows/macOS | Ubuntu 20.04+ |

### 1.2 软件依赖

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| Node.js | >= 18.0.0 | 运行时环境 |
| MySQL | >= 5.7 | 数据存储 |

- 服务端口: 3001（可配置）
- 需要访问MySQL数据库端口（默认3306）
- 如需使用LLM功能，需访问外网API

## 2. 本地开发部署

### 2.1 获取代码

```bash
git clone <仓库地址>
cd "New AI"
```

### 2.2 安装依赖

```bash
npm install
```

### 2.3 配置环境变量

复制环境变量示例文件：

```bash
cp .env.example .env
```

编辑 `.env` 文件，填写必要配置：

```ini
# ========== 必填配置 ==========

# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=aibot
DB_PASSWORD=your_database_password
DB_NAME=faqdb

# JWT认证密钥（请修改为随机字符串）
JWT_SECRET=your_jwt_secret_key_change_this

# 管理员密码
ADMIN_USER=admin
ADMIN_PASS=your_admin_password

# ========== 可选配置 ==========

# 服务端口（默认3001）
PORT=3001

# 运行环境
NODE_ENV=development

# FAQ引擎参数
MIN_CONFIDENCE=0.5
CLARIFY_THRESHOLD=0.65
TOP_K=5
```

### 2.4 初始化数据库

创建数据库和用户：

```sql
-- 登录MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE faqdb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户并授权
CREATE USER 'aibot'@'%' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON faqdb.* TO 'aibot'@'%';
FLUSH PRIVILEGES;
```

系统启动时会自动创建所需表结构。

### 2.5 启动服务

**开发模式**（支持热重载）:
```bash
npm run dev
```

**普通模式**:
```bash
npm start
# 或
node server.js
```

启动成功输出：
```
🤖 FAQ 问答机器人正在启动...
✅ 配置验证通过
   ✅ 系统配置已加载
   📚 正在加载 FAQ 知识库...
   ✅ FAQ 加载完成，共 55 条
   📋 正在加载任务流程...
   ✅ 任务加载完成，共 3 个

🤖 FAQ 问答机器人已启动: http://localhost:3001
   环境: development
```

访问以下地址验证：

## 3. Docker容器部署

### 3.1 构建镜像

```bash
docker build -t faq-bot:latest .
```

### 3.2 运行容器

```bash
docker run -d \
  --name faq-bot \
  -p 3001:3001 \
  -e DB_HOST=your_db_host \
  -e DB_PASSWORD=your_password \
  -e JWT_SECRET=your_secret \
  -e ADMIN_PASS=your_admin_pass \
  -v /path/to/uploads:/app/uploads \
  faq-bot:latest
```

### 3.3 Docker Compose（推荐）

创建 `docker-compose.yml`:

```yaml
version: '3.8'

services:
  faq-bot:
    build: .
    container_name: faq-bot
    ports:
      - "3001:3001"
    environment:
      - DB_HOST=mysql
      - DB_PORT=3306
      - DB_USER=aibot
      - DB_PASSWORD=your_password
      - DB_NAME=faqdb
      - JWT_SECRET=your_secret
      - ADMIN_PASS=your_admin_pass
    volumes:
      - ./uploads:/app/uploads
    depends_on:
      - mysql
    restart: unless-stopped

  mysql:
    image: mysql:8.0
    container_name: faq-mysql
    environment:
      - MYSQL_ROOT_PASSWORD=root_password
      - MYSQL_DATABASE=faqdb
      - MYSQL_USER=aibot
      - MYSQL_PASSWORD=your_password
    volumes:
      - mysql_data:/var/lib/mysql
    ports:
      - "3306:3306"
    restart: unless-stopped

volumes:
  mysql_data:
```

启动：
```bash
docker-compose up -d
```

## 4. 生产环境部署

### 4.1 PM2进程管理

#### 4.1.1 安装PM2

```bash
npm install -g pm2
```

#### 4.1.2 使用配置文件启动

项目已包含PM2配置 `ecosystem.config.js`：

```javascript
module.exports = {
  apps: [{
    name: 'faq-bot',
    script: './server.js',
    instances: 1,
    autorestart: true,
    watch: false,
    maxMemoryRestart: '512M',
    env: {
      NODE_ENV: 'production',
      PORT: 3001,
    },
    error_file: './logs/pm2-error.log',
    out_file: './logs/pm2-out.log',
    merge_logs: true,
    log_date_format: 'YYYY-MM-DD HH:mm:ss',
  }],
}
```

#### 4.1.3 启动服务

```bash
# 启动
pm2 start ecosystem.config.js

# 查看状态
pm2 status

# 查看日志
pm2 logs faq-bot

# 重启
pm2 restart faq-bot

# 停止
pm2 stop faq-bot
```

#### 4.1.4 设置开机自启

```bash
pm2 startup
pm2 save
```

### 4.2 Nginx反向代理

#### 4.2.1 基础配置

```nginx
upstream faq_bot {
    server 127.0.0.1:3001;
    keepalive 64;
}

server {
    listen 80;
    server_name your-domain.com;

    # 聊天客户端
    location / {
        proxy_pass http://faq_bot;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 管理后台（禁止缓存）
    location /admin/ {
        proxy_pass http://faq_bot;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        add_header Cache-Control "no-cache";
    }

    # API接口
    location /api/ {
        proxy_pass http://faq_bot;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 静态资源（长缓存）
    location /admin/assets/ {
        proxy_pass http://faq_bot;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

#### 4.2.2 HTTPS配置

```nginx
server {

    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    # ... 其他配置同上

    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

### 4.3 安全加固

#### 4.3.1 修改默认密码

**必须修改**以下默认密码：

```ini
# .env 文件
DB_PASSWORD=<强密码>
JWT_SECRET=<随机字符串>
ADMIN_PASS=<强密码>
```

生成随机JWT密钥：
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

#### 4.3.2 限制管理后台访问

```nginx
# 仅允许内网访问管理后台
location /admin/ {
    allow 192.168.0.0/16;
    allow 10.0.0.0/8;
    deny all;
    
    proxy_pass http://faq_bot;
}
```

#### 4.3.3 配置限流

系统内置限流配置（`config/index.js`）：

```javascript
rateLimit: {
  chat: { windowMs: 60 * 1000, max: 30 },    // 聊天接口：30次/分钟
  admin: { windowMs: 60 * 1000, max: 120 },  // 管理接口：120次/分钟
}
```

## 5. 数据库配置

### 5.1 数据库表结构

系统使用以下数据表：

| 表名 | 说明 |
|------|------|
| `faq` | FAQ问答条目 |
| `faq_category` | FAQ分类 |
| `chat_log` | 聊天日志 |
| `sys_config` | 系统配置 |
| `task_definition` | 任务流程定义 |
| `chat_session` | 会话上下文 |
| `answer_feedback` | 答案反馈 |

### 5.2 数据库迁移

系统启动时自动执行建表语句，无需手动迁移。

如需手动执行迁移脚本：
```bash
node scripts/migrate-xxx.js
```

### 5.3 数据备份

#### 5.3.1 手动备份

```bash
mysqldump -h localhost -u aibot -p faqdb > backup_$(date +%Y%m%d).sql
```

#### 5.3.2 自动备份

使用项目提供的备份脚本：

```bash
# 执行备份
bash scripts/backup.sh

# 添加到定时任务（每天凌晨2点）
crontab -e
# 添加: 0 2 * * * /path/to/scripts/backup.sh
```

备份策略：
- 保留最近7天的备份
- 备份文件位于 `./backups/` 目录

### 5.4 数据库恢复

```bash
mysql -h localhost -u aibot -p faqdb < backup_20260903.sql
```

## 7. 故障排查

### 7.1 服务无法启动

**现象**: 启动时报错退出

**排查步骤**:

1. 检查端口占用：
```bash
lsof -i :3001
```

2. 检查环境变量：
```bash
node -e "require('dotenv').config(); console.log(process.env.DB_HOST)"
```

3. 检查数据库连接：
```bash
mysql -h localhost -u aibot -p -e "SELECT 1"
```

### 7.2 数据库连接失败

**现象**: 健康检查返回 `database: "disconnected"`

**排查步骤**:

1. 检查MySQL服务状态：
```bash
systemctl status mysql
```

2. 检查连接参数：
```bash
# 测试连接
mysql -h <DB_HOST> -P <DB_PORT> -u <DB_USER> -p<DB_PASSWORD> <DB_NAME>
```

3. 检查防火墙：
```bash
# 检查3306端口
telnet <DB_HOST> 3306
```

### 7.3 FAQ匹配不准确

**排查步骤**:

1. 检查FAQ是否已加载：
```bash
curl http://localhost:3001/api/health
# 查看 faqCount
```

2. 在会话调试页面查看匹配过程
3. 添加更多相似问提高覆盖率
4. 调整最低置信度阈值

### 7.4 内存占用过高

**现象**: 内存持续增长超过限制

**处理步骤**:

1. 查看内存使用：
```bash
pm2 monit
```

2. 重启服务释放内存：
```bash
pm2 restart faq-bot
```

3. 检查是否有内存泄漏（查看日志中的异常）

### 7.5 常见问题速查表

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 服务启动失败 | 端口被占用 | 修改PORT或释放端口 |
| 数据库连接失败 | 密码错误/服务未启动 | 检查.env配置/启动MySQL |
| FAQ不匹配 | 知识库未加载 | 重启服务/检查数据库 |
| 管理后台404 | 静态文件缺失 | 重新构建前端 |
| LLM调用失败 | API密钥错误/网络问题 | 检查配置/网络连通性 |
